Comandos de consola

Comandos primera vez (en su casa)

- Instalar NodeJS

- verificar su instalacion:
node -v

- verificar instalacion de npm:
npm -v

- Instalar manejador de paquetes pnpm
- https://pnpm.io/es/
- https://www.npmjs.com/
npm i -g pnpm

- Verificar instalacion pnpm
pnpm -v

Por proyecto:

- Verificar si no existe el package.json, si no existe ejecutamos:
pn init

- Instalar el paquete five-server
pn add five-server

- Reinstalar paquetes si existe package.json
pn install

- Configurar scripts -> "dev":"five-server"

// -------------

TRABAJAR CON LA CONSOLA command prompt -> cmd

npm i -g pnpm (solo si no está instalado)

pn init (inicializamos)
